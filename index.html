担当所感とポジション

政本様は単なる「効率化」を超え、業務構造そのものをシステムとして再設計する段階に到達しています。GASでタイムカード・報酬反映・契約締結フロー・成績アクセスサイトまで自作しており、すでに社内ポータルサイトに近い仕組みを保有。担当・阿部からも「AI・スプレッドシート・業務連携への理解が深く、自走力が高い」との評価があります。

一方で、活用の高度化に伴い長時間PC作業による身体負担という課題も浮上。直近の5/26では、阿部から共有された「Claudeでウェブサイトを作る」活用法に強く反応し、「やりたいことが出てきた」と自ら次の一歩を発見。まずは情報提供型サイト（自分専用の料理サイト）の制作から着手し、徐々にClaude Codeへと広げていく方針が定まりました。

今回の学びと発見 — key takeaways
01

この進捗サイトの仕組み

このサイトはすべてClaudeで構築されている。毎月のMTG文字起こしをClaudeにアップロードすることで自動的に内容が更新される仕組み。月次の振り返り用としてブックマーク推奨。

Claude チャット
02

プロジェクトで顧客・キャスト別に管理

Claudeの「プロジェクト」機能で、チャットを顧客名ごとに分けて管理できる。文字起こしをアップすればHTMLサイトが更新される。GPTsやGeminiのGemと同じ発想。キャスト管理にそのまま応用可能。

Claude チャット
03

チャット と Claude Code の使い分け

情報を見せるだけのサイトは「チャット」で即作成できる。一方、ログイン・データ入力・管理画面など、相手にアクションしてもらうサイトは「Claude Code」が必要になる。

使い分け
04

実例：レシピサイト

料理を複数選ぶと買い物リストが自動生成され、人数に応じて分量がスケールするサイトを約15分で構築（阿部の私的事例）。薄味など味付けの好みも反映できる。政本様の現行スプレッドシート運用を一気に置き換えられる。

Claude チャット
05

実例：物件探しサイト

ChatGPTのDeep Research（深い調査機能）で「2026年5月時点・公開中の物件のみ」と条件を絞って情報収集→Claudeでサイト化。初期費用シミュレーターも自動で付いてくる。古い情報をつかまないコツも共有。

Deep Research活用
06

実例：業務診断ツール（管理画面付き）

利用者が業務を入力するとAI活用提案レポートが出る診断ツール。回答を集計する管理画面付き。診断画面＋管理画面の2階層はClaude Codeで構築（約4時間）。外注なら30〜50万円相当の規模。

The Road Ahead

次のステップ

5/26のMTGで方針がさらに具体化しました。いきなり難しいことに進まず、まず「Claudeのチャットで情報提供型サイトを作ってみる」ところから。料理サイトを第一歩に、徐々に公開方法やプロジェクト環境、そしてClaude Codeへと広げていきます。

Direction refined on 2026.05.26

まず「作ってみる」。情報提供型サイトから、徐々にClaude Codeへ。

何事も、整理した情報をメモ・スプレッドシート・ウェブサイトのどれで持つかで、見やすさも理解も変わる。Claudeなら構成・デザインの相談から機能追加まで対話で進められる。だからこそ、まずは身近なテーマ（料理サイト）を題材にウェブサイト化を体験し、「できること」の感覚をつかむことが次の一歩です。
